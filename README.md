# EDUCO - Online Computer Science Courses Website

## Project Description
EDUCO is an online learning platform designed for students who want to learn Computer Science and improve their technical skills.

The platform allows students to browse and enroll in Computer Science courses, while instructors can create and manage courses. Administrators can manage users, courses, and platform content.

## Target Users
- Students
- Instructors
- Administrators

## User Roles

### Admin
- Manage users
- Manage instructors
- Manage courses
- Add, edit, and delete courses
- Manage uploaded content
- Access the Admin Dashboard

### Instructor
- Create courses
- View courses
- Edit course information
- Delete courses
- Upload course images and learning materials
- Manage enrolled students

### Student
- Register and login
- Browse Computer Science courses
- View course details
- Enroll in courses
- Access learning materials
- Manage personal profile

## Main Features

### Authentication
- User Registration
- User Login
- Logout
- User Profile Management

### Authorization
- Role-Based Access Control
- Admin Dashboard
- Instructor Dashboard
- Student Dashboard
- Protected pages based on user roles

### CRUD Operations
Courses can be:
- Created
- Viewed
- Updated
- Deleted

Users and course content can also be managed according to permissions.

## File and Image Upload

### Profile Images
Allowed formats:
- JPG
- JPEG
- PNG

Maximum size:

Uploaded by:
- Students
- Instructors
- Admins

### Course Content
- Course thumbnail images
- PDF learning materials
- Course documents

Uploaded by:
- Instructors
- Admins
